# 双腿机器人第三人称控制器

脚本沿用 SingleWheelRobotController 的文件名和类名，以保留已有组件引用；控制逻辑已改为双腿机器人。

## 操作与动画

- W：沿自身朝向前进，播放 Walk。
- S：保持面朝方向倒退，播放 WalkBack。
- A / D：向左 / 向右转向，支持原地转向和移动中转向，叠加侧倾。
- 松开移动按键：平滑减速，停止后播放 Idle。
- 倒退不再叠加程序后倾，也没有轮子骨骼旋转。
- 保留 CharacterController 碰撞、重力与台阶处理，没有跳跃。

## 当前场景部署

已在“场景示例（插画版）”中使用 RobotRoot → VisualPivot → NewRobot 层级：RobotRoot 负责移动和碰撞，VisualPivot 负责侧倾，NewRobot 保留模型和 Animator。旧的 Cute_Robot_05 场景实例已移除。

NewRobot.controller 使用 MoveSpeed 浮点参数：正值切换到 Walk，负值切换到 WalkBack，接近零时回到 Idle；过渡不等待动画播完。参数根据实际移动计算，抵住障碍时会回到待机。原地转向使用 Idle 并叠加侧倾。

六条过渡均使用 0.15 秒固定混合，Interruption Source 设为 None。每次开始切换后先完成这一小段混合，再按当前方向切换；避免持续按键时过渡卡住、目标动画停在开头。

“Assets/机器人/动画/InPlace”中保存 Idle、Walk、WalkBack 的循环原地动画副本。它们保留原动作，去除骨盆曲线中一周期的累计平移，避免模型走出碰撞胶囊。原 FBX 动画保持原样；如替换动作，需要重新准备原地且循环的动画并赋给对应状态。Animator 的 Apply Root Motion 关闭，由 CharacterController 统一控制位移。

Main Camera 的 RobotThirdPersonCamera 已绑定 RobotRoot，保留现有构图偏移，并按新模型高度调整跟随距离和注视高度。碰撞胶囊按模型实际尺寸配置。部署只进行编辑器编译及配置检查，没有进入 Play Mode 或运行场景测试。

## 以后手动更换模型

1. 保持 RobotRoot 直立、缩放为 1，将模型放在 VisualPivot 下；VisualPivot 局部位置、旋转归零，缩放为 1。
2. 调整模型局部位置、旋转和缩放，使脚底对齐 RobotRoot 原点，并面向根物体的 Z 轴正方向。
3. 将 VisualPivot 和模型 Animator 绑定到控制脚本。可以使用组件右键菜单“自动绑定机器人引用”。不要将 Visual Pivot 指向模型或骨骼。
4. 为 Animator 指定含 MoveSpeed 浮点参数及 Idle、Walk、WalkBack 状态的 Controller，并给三个状态配置循环原地动画。
5. 调整 CharacterController 的 Height、Radius 和 Center，使胶囊底部对齐脚底。根物体不要同时挂 Rigidbody 或其他移动控制器；地面需要 Collider。
6. 将独立 Main Camera 的 Target 指向 RobotRoot。不要同时用其他脚本或 Cinemachine 驱动同一相机。

## 常用调节

- Forward Speed / Reverse Speed：前进、倒退速度，默认 2.3 / 1.6。
- Acceleration / Braking：加速和减速强度。
- Turn Speed / Turn Acceleration：转向速度及响应，当前场景保留原来的 60 度/秒转速。
- Turn Lean Angle：最大侧倾，默认 10 度；Stationary Turn Lean 控制原地转向时的侧倾比例。
- Lean Response：侧倾和回正的响应速度。
- Animation Damp Time：移动动画参数的平滑时间。
- Follow Offset / Look At Height：相机跟随距离、拍摄角度和注视高度。
- Framing Offset：沿画面右方、上方平移相机，单位为米；X 为正时机器人偏左，Y 为正时机器人偏下，设置为 0、0 可居中。

脚本直接读取 WSAD，兼容 Input System 和旧输入系统，无需额外配置 Input Actions 或 PlayerInput。测试时先点击 Game 窗口，让键盘输入获得焦点。
